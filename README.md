# 방송 플랫폼 시청자 대상 개인 맞춤형 숏폼 광고 서비스
방송통신위원회 공공데이터 활용 공모전 아이디어 부문 출품작

---

## 소개

본 아이디어는 고정형 TV 시청 기록과 AiSAC 광고 메타데이터를 기반으로 한, 방송 플랫폼 시청자 맞춤형 숏폼 광고 서비스이다. 지상파·케이블 방송 프로그램의 전·후 시청 공백 시간에 맞춤형 숏폼 광고를 삽입함으로써, 시청자에게 비침해적인 광고 경험을 제공하고 광고 효율성과 타겟 도달률을 극대화한다.

해당 플랫폼은 웹 기반 UI 모듈을 통해 방송사 웹 On-Air 서비스에 쉽게 통합할 수 있도록 설계되었다. 사용자는 TV 프로그램 종료 후 다음 프로그램 시작 전까지 자연스럽게 숏폼 광고를 접하며, 광고 스킵 기능을 통해 원하는 광고만 선택적으로 소비할 수 있다. 이를 통해 중간 광고 시청 중 이탈률을 최소화하고 광고 효과를 극대화한다.

초기 추천 광고는 사용자의 성별과 연령대 기반 군집화 결과에 따라 대기열이 구성된다. 서버는 실시간 WebSocket 통신으로 광고를 전송하고 시청자의 광고 시청 정보를 추적하여 업종별 선호도 점수를 도출한다. 이렇게 산출된 사용자 선호도 지표는 데이터베이스에 기록되어, 이후 맞춤 광고를 자동 추천하는 피드백 루프 알고리즘에 활용된다.

---

## 핵심 기능 요약

1. 공공데이터를 활용한 사용자 군집화
2. 실시간 시청 데이터 수집을 통한 사용자 선호도 파악 및 즉각적 피드백 반영
3. 축적된 시청 이력 기반의 개인 맞춤형 광고 추천 알고리즘
4. 프론트엔드–백엔드 간 WebSocket 기반의 실시간 양방향 통신 구조
5. 시청자의 선택권을 보장하는 스킵 가능한 숏폼 광고 인터페이스
6. 사용자의 실시간 선호 업종 정보 시각화

---

## 알고리즘 개요

  사용자의 시청 이력 보유 여부에 따라 두 단계의 추천 알고리즘이 적용된다. 신규 사용자의 경우 초기 추천 알고리즘이 실행되어 해당 사용자가 속한 군집(세그먼트)에 적합한 광고들을 추천하며, 일정량의 시청 데이터가 축적된 기존 사용자의 경우 사용자 행동 기반 알고리즘으로 보다 정교한 개인화 추천을 수행한다.

  시청자의 과거 시청 습관과 취향에 따라 유사한 사람들끼리 그룹화하는 과정이다. 고정형TV 시청률 데이터에서 연령별∙성별 선호 장르 프로필을 도출하고, 해당 프로필에 K-Means 클러스터링 기법을 적용하여 취향이 비슷한 시청자들을 4개의 군집으로 구분하였다. 분류된 군집은 다음과 같다:

● Cluster 0: 특정 장르만 집중 시청하는 군집 (예: 어린이 군집)

● Cluster 1: 다양한 장르를 폭넓게 시청하고 총 시청 시간이 많은 군집 (예: 시니어 군집 )

● Cluster 2: 전체 시청 시간은 길지 않지만 특정 장르를 특히 선호하는 군집 (예: 청년층 군집)

● Cluster 3: 여러 장르를 고루 시청하며 시청 시간도 적지 않은 군집 (예: 중장년 군집)

  이렇게 분류된 군집별 특성치는 각 그룹에게 높은 반응이 예상되는 광고를 선별하는 초기 추천 알고리즘의 본질적 근거가 된다.

# 초기 추천 알고리즘

<p align="center">
  <img src="https://github.com/user-attachments/assets/c4e7263a-a84d-4d81-b9df-1a01f993d012" alt="초기 추천 알고리즘 Workflow" width="500"/>
</p>

사용자가 서비스를 처음 이용하거나 개인 시청 데이터가 없을 때 적용되는 알고리즘으로, 앞서 도출된 시청자 군집별 프로필에 적합한 광고를 추천 대기열로 구성한다. 구현 절차는 다음과 같다.

● 광고-군집 유사도 계산: 한국방송광고진흥공사의 AISAC 광고 DB를 가공하여 광고ID별 메타데이터 CSV를 구축하고, 각 광고와 시청자 군집 간의 콘텐츠 유사도 점수를 계산한다. 구체적으로, TF-IDF 텍스트 임베딩을 통해 광고 제목과 업종 분류 정보에서 핵심 키워드를 추출하고 벡터화한다. 동시에 각 시청자 군집의 선호 장르 역시 키워드 벡터로 표현하여, 코사인 유사도를 활용해 특정 군집과 각 광고의 유사도를 산출한다. 그 결과 해당 군집에 가장 적합한 광고들이 높은 점수를 받게 된다.

● 다양성 확보를 위한 온도 샘플링: 유사도 점수만을 기준으로 상위 광고를 모두 추천하면 유사한 광고만 노출되어 광고 피로도를 유발할 수 있다. 이를 보완하기 위해 유사도 점수를 백분위로 구간화하여 상위 50%, 중위 35%, 하위 15% 비율로 광고를 샘플링한다. 또한 동일 소업종 광고의 과다 추천을 막기 위해 한 대기열에 같은 소업종의 광고가 일정 개수를 넘지 않도록 제한을 두었다. 마지막으로 이렇게 선별된 광고들 중에서는 온도(Temperature) 샘플링 기법을 적용하여 일부 무작위성을 부여함으로써 추천 목록의 다양성과 예측 불가능성을 확보하였다.

# 사용자 행동 기반 알고리즘

<p align="center">
  <img src="https://github.com/user-attachments/assets/2befbe9e-3585-4829-8dca-6d1c5e916e00" alt="사용자 행동 기반 알고리즘 Workflow" width="500"/>
</p>

● 광고 콘텐츠 클러스터링: 다양한 광고를 고르게 노출하기 위해 유사 광고들 간 중복 추천을 피하는 전략을 사용한다. 광고 제목 및 텍스트 정보를 TF-IDF로 벡터화한 후 K-Means 알고리즘으로 약 30개의 광고 클러스터로 분류하였다. 이를 통해 향후 추천 시 동일 업종이라도 서로 다른 클러스터의 광고들을 선별하여 다양한 소재의 광고가 노출되도록 한다.

● 시청 로그 매칭 및 점수화: 사용자의 시청 로그에 기록된 광고 ID로부터 해당 광고의 제목, 업종, 재생시간 등의 정보를 추출한다. 각 시청 기록별로 시청 비율(= 시청시간/영상길이 × 100)을 계산하고, 이를 기반으로 시청 점수를 부여하는데, 일정 비율 이상 시청한 경우 긍정적 반응으로 간주하여 +점수를, 그 미만일 경우 부정적 반응으로 간주하여 –점수를 부여한다. 예를 들어 50% 이상 시청한 광고는 시청 비율에 비례하여 최대 1점까지 가산하고, 50% 미만 시청한 광고는 0점에서 –1점 구간의 감점을 부여하는 방식이다.

● 선호 중분류 업종 도출: 개별 광고에 대한 점수를 같은 중분류 업종끼리 합산하여, 그 총점이 일정 임계값을 넘는 중분류들을 사용자 선호 중업종으로 분류한다. 즉, 사용자가 특정 업종의 여러 광고를 상당 부분 시청하고 긍정 반응을 보였다면 그 업종에 관심도가 높은 것으로 판단한다.

● 선호 대분류 업종 분석: 나아가 대분류(업종 그룹) 관점에서, 해당 대분류 내 여러 중분류에 걸쳐 고르게 긍정 점수를 얻은 경우 해당 대분류를 선호 대업종으로 간주한다. 예를 들어 생활/가전 대분류 안의 가전, 주방, 생활용품 등 여러 중분류에서 모두 높은 점수를 보인다면 그 상위 카테고리에 폭넓은 관심이 있다고 해석한다.

● 추천 후보군 구성: 앞 단계에서 추출된 선호 중업종 및 선호 대업종을 기반으로 후보 광고 리스트를 만든다. 우선 선호 중업종에 속한 광고들을 후보로 모으고, 여기에 선호 대업종 중 아직 포함되지 않은 관련 중업종의 광고들도 추가한다. 그런 다음 앞서 정의한 광고 클러스터 단위로 각 클러스터에서 1개씩 광고를 무작위 선택하여 최종 추천 대기열을 구성한다. 이렇게 하면 사용자가 선호하는 업종을 중심으로 하면서도 다양한 광고 클러스터가 골고루 포함된 균형 잡힌 맞춤 광고 리스트가 만들어진다.

● 추천 결과 출력 및 활용: 최종 선정된 광고들의 행 번호(ID)와 영상 URL 목록을 생성하여 프론트엔드에 전송하고, 함께 중분류 업종별 점수 비율 데이터도 제공한다. 프론트엔드는 이를 받아 막대 그래프 등으로 시각화하여 사용자에게 자신의 관심 분야가 어떻게 분포하는지 피드백한다. 이러한 정보는 사용자에게 흥미를 줄 뿐 아니라, 광고주에게도 개별 광고에 대한 성과 인사이트를 제공할 수 있다.

## 데이터 활용 방안 및 파이프라인

  1. 시청자 시청경향 데이터 수집
  고정형 TV 실시간 장르별 시청시간 및 시청률 데이터(2021.04~2023.12)를 활용하여 시청자들의 장르 선호도를 분석한다. 해당 데이터는 한국방송광고진흥공사(KOBACO) 방송통계포털에서 제공되며, 연령대∙성별∙장르별 시청 시간 및 시청률 정보를 포함한다. 이를 바탕으로 시청자 군집(클러스터)을 도출하고 세그먼트별 프로파일을 생성한다. 각 군집별 주요 시청 장르와 패턴을 파악함으로써 맞춤형 광고 타겟팅 기준을 구축한다.

  2. 광고 메타데이터 수집
  AISAC 광고소재명별 광고 정보 데이터(2011.11.18~2024.07.31)를 활용하여 개별 광고의 메타데이터를 수집한다. 해당 데이터는 한국방송광고진흥공사가 공개한 공공데이터로부터 얻을 수 있으며, 각 광고 소재의 제목, 대∙중∙소업종 분류, 제작연도 등의 정보를 포함한다. 이 메타데이터는 광고 추천 알고리즘의 입력 데이터로 활용되어, 사용자 선호 업종 점수 계산 및 시청 로그 데이터 매칭에 사용된다.

  3. 광고 영상 데이터 수집
  각 광고 소재별 실제 광고 영상 데이터(URL 및 재생시간)를 안정적으로 확보하기 위해, 본 서비스는 AISAC 광고 아카이브를 크롤링하여 동영상 URL과 길이 정보를 자동 수집하는 시스템을 갖추었다. ad_to_AISAC_URL.py 등의 파이썬 스크립트를 통해 상위 10,000여 개 광고 소재의 동영상 URL과 재생 시간을 크롤링 및 추출하여 CSV 파일로 구축해 두었다. 서비스 운영 시에는 이 사전 구축된 영상 URL 데이터베이스를 활용함으로써 광고 재생 지연을 최소화하고 즉각적인 응답성을 보장한다.

  4. 시청자 행동 데이터 수집
  서비스 이용 중에는 시청자의 상호작용 데이터가 실시간으로 수집된다. 시청한 광고의 ID, 시청 시간, 스킵 여부 등의 시청 이력이 밀리초 단위 정밀도로 기록되고, WebSocket을 통해 서버로 실시간 전송된다. 이를 통해 거의 실시간에 가까운 피드백 루프가 형성되며, 수집된 데이터는 데이터베이스에 저장되고 추천 알고리즘의 입력으로 활용된다.

  5. 데이터 파이프라인
  수집된 데이터는 적재∙가공∙분석 단계를 거쳐 최종적으로 추천 서비스에 활용된다. (예: 시청률 원천 데이터 → 전처리/군집화 → 군집 프로필 DB 저장, 광고 메타데이터 크롤링 → 광고 DB 구축, 실시간 시청 로그 → 선호도 분석 테이블 업데이트 등). 이러한 파이프라인 전 과정의 자동화를 통해 데이터 기반 서비스 운영의 안정성을 높였다.

## 주요 모듈 컴포넌트

● main.py: 사용자 행동 기반 광고 추천 알고리즘 구현 모듈. (시청 로그 수신, 광고 선호도 점수 계산 및 추천 결과 생성)
- server.py: 웹 서비스 백엔드 서버. 광고 추천 대기열 전송, 사용자 시청 데이터 수신 및 저장을 담당하며, Flask-SocketIO를 통해 프론트엔드와 실시간 양방향 연결을 유지한다.
- index.html: 프론트엔드 On-Air 서비스 페이지 및 광고 슬라이드 UI. 방송사 온에어 영상 플레이어에 광고 슬라이더를 통합한 형태로, 좌우 슬라이드로 광고 영상을 표시하고 현재 시청 시간과 사용자 선호도 그래프를 함께 보여준다.
- AdRecommender.py: 클러스터별 맞춤 광고 추천 엔진 모듈. 사용자 군집(세그먼트)에 따라 적합한 광고 리스트를 산출하는 초기 추천 알고리즘이 구현되어 있다.
- ad_to_AISAC_URL.py: AISAC 광고 아카이브에서 광고 소재별 동영상 URL과 재생 시간을 자동으로 수집해 CSV 데이터베이스를 구축하는 크롤러 스크립트이다. (현재 프로토타입 서비스 구조에서는 사용되지 않으나, 대용량 광고 영상 URL 사전 확보를 위해 개발됨.)

## 기술 스택

● 백엔드: Python 3.11
- NumPy, Pandas: 대용량 시청 데이터 처리 및 CSV 파일 입출력
- Flask + Flask-SocketIO: 실시간 웹소켓 통신 (양방향 데이터 송수신)
- Scikit-learn: 머신러닝 알고리즘 구현

● 프론트엔드: Web (HTML5, CSS3, JavaScript)
- HTML5/CSS3: 사용자 친화적인 웹 인터페이스 구현
- JavaScript: 영상 재생 로직, 사용자 시청 시간 추적 및 UI 동작 처리
- Socket.IO: Python-자바스크립트 간 실시간 양방향 통신 구현 (웹소켓 프로토콜)
